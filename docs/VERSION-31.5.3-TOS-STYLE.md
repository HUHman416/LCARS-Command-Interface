# Version 31.5.3 Development — TOS Console Style

The operator supplied a TOS character sheet as an additional visual reference and requested an update in that direction. The optional Enterprise Original Series skin now uses pure black fields with flat yellow (`#ffdd00`), green (`#39e639`), cyan (`#00bfff`), and orange-red (`#ff3200`) controls, larger white Roddenberry headings, and thin white rules.

Following further operator review and supplied resin-button photographs, large red/yellow fields and broad section bars were reduced. Overview sections use white legends, thin rules, and small colored panel-code blocks. Translucent blue, green, ivory, and amber keycaps, jelly-bean station switches, and small domed lamps reproduce the physical vocabulary of the supplied TOS references using original CSS highlights and bevels. Station keys retain consistent geometry, numeric legends, separate printed labels, and an underlined active selection. Red is used sparingly for signals and Power. Fewer enclosing card borders and generous black separation replace the muted dashboard treatment. Current-load and memory/storage instruments share the brighter palette while retaining actual sampled values and accessible descriptions. Settings, dialogs, and the TOS theme preview follow the same visual direction. Selected Settings category labels explicitly use black text on light ivory caps, including High Contrast mode. Compact layouts use the existing mobile command bar and its Tray Deck rather than overlapping Speed Dial controls. Tasks, Tray, and Power remain pinned below the independently scrolling station bank.

The supplied PDF remains an external, fan-made reference; it is not bundled, traced, or treated as application instructions. Its gray surround is intentionally excluded because the operator explicitly requested a black background. The original console photographs and graphics remain complementary references.

All three supplied fonts and four console recordings remain. Existing sound preferences, accessibility modes, detached views, desktop functions, and six other display families are retained. Android changes synchronize the build version only. Version 31.6 remains reserved for Security, Recovery, and Accessibility; Version 30 remains Stable.

Validation: 201 JavaScript regressions and 69 Python tests pass. Both hosted and Electron renderer builds pass, together with Python compilation, desktop process syntax, normal shell syntax, and whitespace checks. Browser checks cover the desktop overview and Settings, the selected-label contrast repair in normal and High Contrast modes, Reduced Motion, color-safe active markers, portrait (390 × 740), short landscape (580 × 420), and access to compact Tray and Power controls. The existing baseline TypeScript diagnostics documented in 31.5.1 remain outside this visual update. Native packages are gated by the standard Development workflow.
