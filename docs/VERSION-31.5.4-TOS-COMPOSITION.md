# Version 31.5.4 Development — TOS Console Composition

The operator selected the 31.5.2 screenshot as the preferred structural reference and requested a stronger palette without a movie-era appearance. This update restores that composition and typography: paired cyan-framed monitors, an amber memory/storage instrument, compact Roddenberry headings, printed navigation labels, and a two-column bank of consistently shaped rectangular keys. The all-black surrounding surface remains.

Controls use stronger blue, green, ivory, and yellow with subtle translucent highlights and small bevels based on the supplied resin-button photographs. Red remains a small signal accent. The character sheet guides palette and label clarity; the broad colored bands, enlarged headings, and capsule-shaped station keys explored in 31.5.3 are superseded. Application and station keys retain readable text and stable geometry.

Selected Settings categories use black heading and description text on light ivory keys, including High Contrast mode. Tasks, Tray, and Power stay pinned on desktop. Compact layouts retain the existing Command Deck and Tray route, with the overlapping Speed Dial strip hidden. The three supplied fonts, four console recordings, actual telemetry values, accessibility preferences, detached views, and six other display families remain.

Validation: 201 JavaScript regressions and 69 Python tests, hosted and Electron renderer builds, normal syntax and whitespace checks, and browser review of the restored overview, Settings contrast, accessibility modes, and compact layouts. Existing baseline TypeScript diagnostics are documented in 31.5.1. Native packages are gated by the standard Development workflow.

Version 31.6 remains reserved for Security, Recovery, and Accessibility. Version 30 remains Stable.
