# Version 31.5.5 Development — TOS Palette Restraint

Repeated green controls and load bars made the optional TOS skin read as a later-film console. The supplied button references now guide a mixed ivory, blue, amber, and restrained coral palette. Green is confined to small indicator lamps. The preferred 31.5.2 composition remains: rectangular resin keys, compact printed labels, paired cyan-framed monitors, amber allocation graphic, black fields, and Roddenberry headings.

Inherited action variables, station and application keys, notices, clock strip, numeric readouts, compact navigation, and Speed Dial no longer default to green. Load bars use the same ivory/amber/blue channel colors as the numeric bank; high-load end segments remain coral. The storage allocation ring uses blue. Values, ranges, labels, and telemetry actions are unchanged. Small success/indicator lamps remain distinguishable without dominating the panel.

The readable selected Settings labels, accessibility modes, pinned Tasks/Tray/Power controls, all three fonts, all four recordings, detached views, and other display families remain. Version 31.6 remains reserved; Version 30 stays Stable.

Validation: 201 JavaScript regressions and 69 Python tests pass, together with hosted and Electron renderer builds, normal syntax checks, and whitespace checks. Browser review confirms the preferred overview geometry, no large green background surfaces, readable selected Settings labels in normal and High Contrast modes, and disabled lamp animations under Reduced Motion. Native packages are gated by the standard Development workflow.
