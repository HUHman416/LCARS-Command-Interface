# Version 30.13 Horizontal Systems Navigation

Version 30.13 is a focused layout and accessibility pass over the unified Systems page introduced in Version 30.12.

## Navigation behavior

- All eleven Systems sections occupy one horizontal control deck at ordinary desktop widths.
- Compact labels replace full names before the deck needs overflow; the toolbar always displays the active section's full name.
- Narrow windows retain a single horizontal row with visible previous and next controls, pointer or touch scrolling, a visible scrollbar, and Left/Right Arrow navigation.
- Selecting a section automatically reveals its tab, including when another LCARS page routes directly to Wi-Fi, audio, storage, or a different system control.
- The deck and active-section toolbar remain visible while moving down a long Systems page.

## Vertical-space reductions

- The embedded Systems masthead and active toolbar are shorter.
- Four live telemetry meters remain in one row at normal compact-desktop widths.
- The telemetry detail matrix remains two-column until the viewport is genuinely narrow.
- Processor cores, physical memory modules, graphics adapters, engineering sensors, and storage records fill horizontal space with adaptive columns before increasing page height.

## Preserved behavior

No Systems sections or native controls were removed. Version 30.12's unified CPU, GPU, memory, disk, hardware, storage, and engineering data remains available, along with every Version 30.11 native system-control route.
